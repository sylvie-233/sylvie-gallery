# 希尔薇图集 v1

> 视觉基调：深色 + 玫红强调色（`#ff2d55`）｜结构：全部页面共用 Header + 内容区 + Footer｜适配：PC / H5 双端
> 核心权限：**所有图集仅管理员可发布**，注册会员与付费会员均无上传/发布入口

## 全局框架

### 顶部 Header
- 左侧站点标识：**Logo + 标题**
  - Logo：32×32 圆角渐变方块（玫红 → 橙红），内为白色「希」字，带红色柔光；与页脚、管理后台同款，点击回首页
  - 标题：希尔薇图集（17.5px 加粗，字距 0.5px）
  - 浏览器标签页 favicon 使用同一 Logo（内联 SVG，圆角渐变方块 + 希字）
- 主导航 Tab：首页 / 图集 / 瀑布流 / 标签 / 会员 / 公告，**每项文字前带线性小图标**（房子 / 图片 / 瀑布块 / 标签 / 皇冠 / 铃铛），悬停与选中时图标提亮
- 右侧功能：搜索框、登录 / 注册按钮（**默认红色实心**，悬停提亮）
- 登录后：按钮替换为用户头像图标（付费会员带皇冠角标）
- 移动端：标题文字收起只留 Logo，导航转为可横向滚动的二级标签条，搜索框自适应铺满
- 全站可点击元素（链接、按钮、卡片、标签、通知条目等）统一手型光标，禁用态保持默认箭头

### 用户菜单（点击头像展开）
- 个人中心
- 我的通知（未读红点）
- 我的收藏
- 我的购买
- 管理后台 · 发布图集（仅管理员账号可见）
- 退出登录

### Footer（所有页面底部通用 · 单行紧凑条）
- 左侧：站点标识（**同款「希」字渐变方块 Logo + 希尔薇图集**，logo 24px），点击回首页
- 中部：`友情链接` 标签 + 友链胶囊（粗体站名 + 一句简介），如 `片舟 · 发现好剧 下载好剧`，可横向扩展多个
- 右侧：版权信息 `© 2020-2026 希尔薇图集. All rights reserved.`
- 整条高度约 60px，上下细分割线，不抢占内容区视觉
- 移动端（≤640px）：三段改为居中纵向堆叠

### 关键操作二次确认
- 统一确认弹窗：红色警示图标 + 标题（带问号）+ 后果说明 + 「取消 / 确认」双按钮
- 覆盖的关键操作：
  - 退出登录（提示本地解锁记录会保留）
  - 删除评论 / 删除回复（提示不可恢复）
  - 积分解锁图集（展示消耗与剩余积分）
  - 管理员发布图集（展示标题与归属作者）
- 取消后不产生任何副作用；确认后关闭弹窗再执行
- 购买流程本身已有「确认订单 + 立即支付」弹窗，不再二次叠加

## 首页

### 最近更新
- 按发布时间倒序展示最新 24 套图集，默认 **4 行 × 6 列**（桌面）
- 响应式降列：≤1080 五列 / ≤900 四列 / ≤760 三列 / ≤560 两列
- 卡片：封面、图片数 / 视频数徽章、标题、作者头像与名称、收藏数
- 区域标题右侧显示「今日新增 N 套 · 最近更新 日期」
- 「查看全部」跳转图集页

### 个人写真
- 红色小标题，下方为一排作者图卡（PC 7 列 / 手机 3 列、超窄屏 2 列）
- 每张卡：方形（1:1）封面图 + 右上角深色徽章显示该作者名下**图集数量** + 图下居中显示作者名
- 鼠标悬停：卡片上浮、名称变玫红
- 区块右上角「查看全部 ›」进入**作者列表页**
- 点击卡片进入**作者主页**（独立页面，非图集页筛选）

### 公告
- 展示最新 4 条公告：类型标签（置顶 / 更新 / 活动 / 维护 / 规则）、标题、日期
- 「全部公告」跳转公告页

## 作者列表

### 页面结构
- 标题「个人写真」+ 副标题「图集作者 · 写真本人 · 点击进入作者主页」
- 工具区：独立搜索框（占位「搜索作者名 / 别名」）+ 右侧「共 N 位作者」计数
- 下方作者图卡网格，样式与首页完全一致（封面 / 图集数徽章 / 名称）

### 交互
- 搜索框输入即时过滤，匹配范围：姓名、别名、风格标签
- 无匹配时展示空态「没有找到这位作者 / 换个名字或别名试试」
- 点击卡片进入该作者主页
- 从其他页面重新进入时清空搜索词

## 图集（核心列表页）

### 排序
- 三个排序维度：最新（发布时间）/ 热门（浏览量）/ 收藏（收藏数）
- 单选切换，默认「最新」

### 写真卡片
- 封面图（3:4）
- 右上角徽章：图片数 `37P`、视频数 `1V`（无视频时不显示）
- 标题（最多两行）
- 底部信息行：作者头像 + 作者名称 + 收藏数（星标可一键收藏）
- **不含点赞功能**，全站不出现点赞数与点赞按钮

### 筛选与分页
- 网格与首页不同：桌面 **5 列**（每页 24 套），随宽度降为 4 / 3 / 2 列
- 支持按标签 / 关键词筛选，筛选条件以可关闭的标签形式展示
- 每页 24 套，底部页码分页（上一页 / 数字 / 下一页）
- 空结果时展示兜底提示

## 作者主页

> 从首页「个人写真」卡片、详情页面包屑、作者 chip、右栏「作者 / 合集」、评论区作者名进入，是独立页面而非图集页的筛选态

### 介绍卡
- 左侧方形头像（1:1；后台已上传图片则显示图片，未上传时显示渐变底 + 首字）
- 右上方第一行：作者名（玫红加粗）+ 右侧**订阅 / 已订阅按钮**（未登录点击唤起登录）
- 元信息行：入驻日期 / `收录 N 套 · 当前可下载 N 套` / 最近更新日期 / 别名
- 说明句：其中 N 套提供原图压缩包；积分解锁后可在线查看全部并下载，付费会员全站畅看
- 简介：默认收起（PC 2 行 / 手机 3 行，超出省略），「展开更多 ∨ / 收起 ∧」切换
- 不展示积分、解锁下载、权益已用完等信息

### 相关图集
- 红色小标题「相关图集」+ 总套数
- 复用图集卡片（封面、P/V 徽章、标题、作者、收藏数）
- 按发布时间倒序，每页 12 套，底部页码分页，翻页后回到页面顶部

## 瀑布流

- 多列不等高瀑布流，列数与图集页一致：桌面 **5 列**（首屏约 4 行）、随宽度降为 4 / 3 / 2 列
- 内容为「个人推荐」：按浏览与收藏偏好推荐图集
- 无限滚动：首批直接铺满 24 张（约 5 行 × 5 列），滚动接近底部每次追加 12 张，累计 48 张后提示「已经到底啦」
- 卡片样式与图集页一致，收藏可直接在卡片上操作且不打断滚动位置

## 标签

### 标签云
- 收录全站标签，字号按收录套数分级（5 档）
- 每个标签文案前统一带 `#` 前缀（如 `#日系`），后接收录数量
- 点击标签跳转到「图集」页的标签筛选结果

### 标签结果页
- 复用图集卡片列表的样式与排序
- 顶部显示当前标签筛选条件（可关闭 / 可清除全部）
- 下方保留分页按钮

## 会员

### 注册会员卡片
- 定价：免费（邮箱注册即得）
- 权益：每套可预览前 3 张、收藏 / 关注作者 / 评论、每日签到领积分（可解锁单套）、更新提醒
- 操作：免费注册

### 付费会员卡片
- 定价：¥19 / 月（按月计费，30 天到期后可续费）
- 权益：全站图集在线畅看、不限量打包下载无水印原图、新图提前 3 天、专属客服
- 操作：立即开通（**仅支持支付宝**）
- 说明：会员不可上传或发布内容
- 详情页解锁区、会员页、个人中心、我的购买共用同一套付费会员逻辑（`state.vip`）

## 公告

### 列表
- 公告条目：类型标签（置顶 / 更新 / 活动 / 维护 / 规则 / 通知）、标题、摘要、日期
- 置顶公告排首位，标签用玫红样式，其余为灰色标签
- 每页 8 条，底部页码分页（上一页 / 数字 / 下一页）

### 搜索
- 页面上方独立搜索框，占位「搜索公告标题 / 内容」
- 输入即时过滤，匹配范围：标题、摘要、正文、类型标签
- 右侧显示「共 N 条 · 第 x / y 页」，无结果时展示空态并隐藏分页

### 详情
- 点击条目弹层展示公告全文（日期 + 类型 + 分段正文）

## 写真详情页

### 左栏 · 上部信息卡
- 面包屑（在卡片外）：首页 › 图集 › 作者名 › 图集标题，前三段可点击
- 信息整体收进一张圆角深色卡片：
  - 卡片右上角：收藏 / 分享 两个按钮；收藏后按钮高亮为「已收藏」（实心红心），与侧栏收藏状态同步
  - 标题：玫红加粗大字，长标题自动换行
  - 元信息：发布日期 + 时分秒 · 浏览量
  - 描述文案按状态切换：
    - 未登录：「登录可预览 3 张，解锁后在线看全部；原图压缩包 XXXMB，解锁后下载」
    - 已登录：「可预览 3 张，解锁后在线看全部；原图压缩包 XXXMB，解锁后下载」
    - 已解锁：「已解锁，可在线查看全部；原图压缩包 XXXMB，可打包下载」
  - 简介：一段较浅色的说明文字
  - 标签行（一排 chips）：
    - 作者（红色旗标图标 + 姓名）→ 点击进入该作者图集列表
    - 订阅 / 已订阅（铃铛图标，琥珀色）→ 未登录唤起登录，订阅成功后转为灰色「已订阅」
    - `53P` 图片数
    - `#标签` ×N → 点击进入对应标签结果

### 左栏 · 下部内容
- 视频卡片置顶（有视频时）：播放按钮、时长、「视频」徽章
- 图片卡片：右下角显示「当前 / 总数」
- 预览与解锁规则（**游客与注册会员一致，未解锁都只看前 3 张**）：
  - **未解锁**：只展示前 3 张图片，接锁定区
    - 标题「还有 N 张图片未解锁」（N = 总数 − 3）
    - 左卡随登录状态变化：
      - 游客「免费注册」：登录后用 N 积分解锁完整 N 张图集 + 描边按钮「登录 / 注册」
      - 注册会员「N 积分看这一套」：解锁后可查看完整 N 张并支持下载 + 描边按钮「N 积分解锁」
    - 右卡「付费会员」（红色描边高亮）：价格「¥19 / 月」+「全站图集无限畅看，整包下载原图」+ 实心红按钮「立即开通」
  - **已解锁（积分解锁 / 付费会员）**：展示全部图片 + 「已解锁全部 N 张内容 · 打包下载（大小）」
- 右栏主按钮随状态变化：`登录解锁` / `N 积分解锁` / `下载全部`

### 左栏 · 评论区
- 评论数统计
- 发布框：登录后可发布，未登录点击唤起登录；提示「评论与回复经管理员审核后展示」
- 一级评论：头像、昵称、等级徽章（注册会员 / 付费会员）、时间、内容、回复
- 嵌套回复：左侧竖线缩进，展示「回复 @某人」、审核状态标签（管理员审核后展示）、时间
- 本人内容可删除；删除后即时生效
- 回复框：行内展开，提交后进入审核状态

### 右栏 · 当前图集
- 标题 + 浏览量
- 四宫格数据：图片数、视频数、下载积分、压缩包大小（MB）
- 操作区：解锁 / 下载（主按钮）+ 收藏 + 分享

### 右栏 · 作者 / 合集
- 作者方形头像（后台上传的图片或色卡首字）、名称、共收录套数
- 「查看全部」进入作者主页
- 提示：优先浏览同合集内容

### 右栏 · TA 的其他作品
- 该作者其他图集 5 条：缩略图、标题（强调色）、图片数
- 「查看更多」进入作者主页

### 右栏 · 继续浏览
- 作者名 + 相关联标签：作者名进入作者主页，标签进入标签结果

### 移动端处理
- 右栏内容折叠：数据以四格信息条形式并入左栏，底部固定操作条（解锁 / 下载、收藏、分享）
- 图片与评论单列铺满

## 用户系统

### 注册
- 以**邮箱注册为主**：昵称 + 邮箱 + 密码（≥6 位）
- 注册成功即自动登录

### 登录
- 邮箱 + 密码
- 弹窗顶部带品牌块：同款「希」字渐变方块 Logo + 希尔薇图集 + 副标语「高清写真 · 每日更新」，浅红渐变底
- 登录成功后 Header 右侧显示头像图标
- 头像菜单：个人中心 / 我的通知 / 我的收藏 / 我的购买 / 退出登录

### 个人中心
- 账号信息：头像、昵称、会员等级徽章、邮箱
- 数据概览：收藏数、购买数、订阅数
- 账号详情：邮箱、会员状态与有效期、下载积分、已订阅作者数
- 最近收藏预览（最多 4 套）
- **已订阅作者**：与首页「个人写真」一致的**方形卡片**（1:1 封面 + 右上角图集数徽章 + 图下作者名），点击进入作者主页；未订阅时展示引导空态
  - 每页 12 位，标题旁显示「N 位 · 第 x / y 页」，底部页码分页
- **编辑资料**：昵称下方「编辑资料」按钮，打开弹窗
  - 头像：8 个预设色卡（渐变底 + 昵称首字），选中项白色描边高亮；支持上传自定义头像（jpg / png / webp，≤2MB，本地读取即时预览），上传后色卡上方出现缩略图，可随时切回预设色卡
  - 昵称：1–16 字符，空值与超长会拦截并提示
  - 邮箱：登录账号，只读不可改
  - 保存后同步更新顶部头像、用户菜单、个人中心与评论区头像；数据持久化到本地

### 我的通知
- 顶部：`全部 N / 未读 N` 分段切换，中间显示「共 N 条 · 第 x / y 页」，右侧「全部标为已读」
- 单条通知：类型图标（审核 / 更新 / 权益 / 系统，四种配色）+ 标题 + 类型标签 + 时间 + 描述 + 未读红点
- **点击单条弹出「通知详情」弹窗**（同时标为已读、红点消失），已读状态持久化到本地
- 详情弹窗：类型图标 + 类型标签 + 时间 + 标题 + 描述正文
  - **更新类型**通知附带关联图集卡片（缩略图 + 标题 + `P/V · 作者 · 日期`），点击卡片直接**跳转到该图集详情页**
- 每页 5 条，底部页码分页（上一页 / 数字 / 下一页）；切换全部 / 未读时回到第 1 页
- 切到「未读」且无未读时展示空态提示

### 我的收藏
- 已收藏图集卡片列表，可取消收藏
- 每页 12 套，顶部显示「共 N 套 · 第 x / y 页」，底部页码分页

### 我的购买
- 顶部概览三格：累计消费 / 会员订单数 / 已解锁图集数
- 会员订单卡片：皇冠图标、套餐名、订单号与支付时间、金额、生效状态与到期日、「续费」按钮
  - 续费时在剩余有效期基础上叠加 30 天，不会清零
- 图集解锁卡片：缩略图、标题、`37P · 1V · 300.10 MB · 作者`、消耗积分、状态、「查看」跳转详情
- 图集解锁列表每页 6 条，标题旁显示「共 N 条 · 第 x / y 页」，底部页码分页
- 无任何记录时展示空态与「去看看会员」入口

> **管理后台** 为独立项目，功能清单已拆分至《美女写真网站-v1管理后台功能清单.md》，
> 原型见 `美女写真网站-v1管理后台原型.html`；与前台共用同一套数据库（见 v1 数据库设计 SQL）。
>
> 前台与后台各自独立部署、独立登录：前台 `admin@sylvie.cc` 登录后仅显示「管理后台 · 发布图集」快捷入口，
> 实际的内容管理与运营操作全部在独立后台完成。

## 权限与角色

### 游客
- 浏览首页 / 图集 / 瀑布流 / 标签 / 公告 / 会员页
- 图集详情只能看前 3 张预览图，可浏览评论区
- 收藏、订阅、评论、解锁、下载均需登录

### 注册会员（免费）
- 每套图集同样只预览前 3 张（与游客一致）
- 收藏、订阅、评论、签到领积分
- 用积分解锁单套图集：解锁后查看全部 + 支持下载
- **无发布权限**

### 付费会员
- 全站图集在线畅看 + 不限量打包下载原图
- 评论区徽章显示「付费会员」，个人中心与我的购买同步展示有效期
- **无发布权限**

### 管理员
- 唯一可发布图集的角色
- 发布流程：标题 → 作者 → 标签 → 批量上传图片 / 视频 → 发布
- 上传后自动生成缩略图并进入审核队列
- 完整的图集上下架、评论审核、公告与页脚配置在**独立管理后台**完成
