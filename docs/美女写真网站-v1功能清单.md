# 美女写真网站 v1

## 前台功能

### 首页
- 精选推荐位（编辑推荐 / 今日热门）
- 最新上传列表
- 分类快捷入口
- Banner 运营位
- SEO：TDK 配置

### 图集列表页
- 分类 / 标签筛选
- 排序（最新 / 最热 / 评分）
- 分页或瀑布流加载
- 缩略图懒加载
- 每图集：标题、封面、张数、浏览量

### 图集详情页
- 大图浏览（翻页 / 键盘操作）
- 图片预加载
- 浏览量 / 点赞 / 收藏
- 标签与相关推荐
- 下载按钮（受权限控制）

### 用户系统
- 注册 / 登录（邮箱 / 手机号）
- 第三方登录（预留 v1 简化）
- 个人中心
  - 我的收藏
  - 我的点赞
  - 浏览历史
  - 账号设置
- 会员等级（免费 / VIP）

### 付费与会员
- VIP 订阅（月 / 季 / 年）
- 单套图集购买
- 支付接入（微信 / 支付宝）
- 订单与支付记录
- 防盗链与权限校验

### 搜索
- 关键词搜索（标题 / 标签 / 模特名）
- 热搜词推荐
- 搜索结果筛选与排序

## 后台管理

### 内容管理
- 图集上传（批量 / 打包 zip）
- 图片压缩与多尺寸缩略图生成
- 分类 / 标签管理
- 模特资料管理
- 图集上下架 / 审核

### 运营管理
- 首页推荐位配置
- Banner 管理
- 公告管理
- 热搜词配置

### 用户与订单
- 用户列表 / 状态管理
- 会员订单查询
- 退款处理

### 系统管理
- 管理员账号与角色权限（RBAC）
- 操作日志
- 系统设置（站点信息 / SEO）

## 技术支撑

### 图片与存储
- 对象存储（OSS / COS）
- CDN 加速
- 水印（图片防盗用）
- 防盗链（Referer / 签名 URL）

### 性能与安全
- 缓存（Redis：热门图集 / 排行榜）
- 接口限流
- 敏感内容合规审核（上传先审后发）
- HTTPS 全站

### 数据统计
- PV / UV 统计
- 图集热度榜
- 用户行为埋点（预留）

## 非功能需求
- 响应式适配（PC / H5）
- 移动端优先体验
- 合规：年龄声明、内容免责声明、ICP 备案
- v1 范围外（预留）：评论社区、APP、AI 打标签、多语言
