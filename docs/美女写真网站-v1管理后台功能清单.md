# 希尔薇图集 · v1 管理后台功能清单

> **独立项目**：管理后台与前台（`美女写真网站-v1原型设计.html`）是两个独立的应用，
> 各自独立部署、独立登录，仅共用同一套数据库（见 `美女写真网站-v1数据库设计.sql`，权限依赖 `user.role='admin'`）。
> **仅面向桌面端**：后台是运营人员在内网 / 桌面浏览器里使用的工具，按 1280px 及以上的桌面布局设计（侧栏 220px 固定、表格多列并排），不做移动端适配；移动端只面向 C 端前台。
> 原型：`美女写真网站-v1管理后台原型.html`（单文件，深色 + 玫红设计语言，与前台视觉统一）。
>
> **登录**：邮箱 + 密码，仅 `role=admin` 可进入；v1 无多角色权限分配，一个后台即全部运营能力。
> 前台管理员登录后仅显示「管理后台 · 发布图集」快捷入口，内容管理与运营操作全部在本后台完成。

## 功能模块

### 整体结构
- 左侧导航 10 项：数据看板 / 图集管理 / 发布图集 / 评论审核（未处理数红色徽章）/ 公告管理 / 作者管理 / 支付流水 / 用户管理 / 友链与配置 / 操作日志
- 顶部：面包屑（管理后台 / 当前页）+ 右侧管理员账号与角色角标
- 底部：返回前台、退出登录（二次确认）
- 所有写操作成功后追加一条操作日志，日志页实时刷新

### 数据看板
- 四张统计卡：图集总数（含已发布/草稿拆分）、注册用户、付费会员、待审核评论（橙色警示）
- 最近发布表格：最新 6 条，缩略图 + 标题 + 作者 + `P/V` 规格 + 发布时间 + 状态徽章（已发布/草稿/已下架）；标题右侧「全部图集 ›」直达图集管理
- 右侧快捷操作：发布新图集、审核待处理评论、发布公告、修改站点配置
- 今日概览：PV/UV（演示值）、下载次数、**积分解锁套数与新订单/营收按支付流水实时计算**（与流水页今日营收同口径，避免两页数字打架）

### 图集管理
- 状态筛选：全部 / 已发布 / 草稿 / 已下架；按标题或作者搜索（回车或点「搜索」，**搜索自动回第 1 页**）
- 表格列：封面缩略图 + 标题 + `#ID`、作者、`P/V` 规格、解锁积分、浏览/收藏（万级折算）、发布时间、状态徽章
- 操作：已发布可「下架」，草稿/已下架可「发布/上架」，均二次确认；「删除」二次确认后不可恢复
- **编辑**：每行「编辑」按钮打开编辑弹窗（标题 `#ID` 标记）
  - 可改：标题（必填 1–60 字，空值拦截）、归属作者、解锁积分、简介、标签（搜索下拉添加，最多 8 个，已选标签以 `#标签` 胶囊展示，点 ✕ 或再点下拉项即可移除）
  - 弹窗预填当前值，作者下拉自动选中原作者；标签下拉中已选项目带 ✓ 并高亮，打开即列出全部标签
  - 保存后列表与看板同步刷新，前台立即生效；操作日志记录「编辑图集」并列出改动字段（标题 / 作者 / 积分 / 简介 / 标签）
  - v1 不支持在编辑中替换媒体文件（图片 / 视频 / 封面），需更换请删除后重新发布；取消编辑不改动数据
- 每页 6 套，底部页码分页；空结果兜底提示
- 操作后看板统计与列表同步刷新

### 发布图集
- 左栏基本信息：标题（必填，1–60 字，空值拦截）、归属作者下拉、解锁积分、简介、标签、发布规则提示
- 标签选择为**搜索下拉框**（不再平铺全部标签）：输入关键词实时筛选、聚焦展开全部、↑ 支持回车选中首个未选项、Esc 或点击空白处收起；已选项以 `#标签` 胶囊显示在输入框上方，最多 8 个，超出提示「最多选择 8 个标签」
- 右栏媒体：虚线上传区（点击/拖拽批量上传图片，缩略图网格带序号与删除按钮）、视频数量（0–3）、封面说明（默认取第 1 张）
- 「发布图集」→ 二次确认（展示标题、作者、图片数）→ 写入列表并置为已发布，表单（含标签胶囊与搜索词）自动重置，提示「发布成功，已在前台展示」
- 发布成功自动生成缩略图并进入审核队列（对应数据库 `album.status` 与 `admin_op_log`）

### 评论审核
- 分段 Tab：待审核 / 已通过 / 已拒绝
- 搜索：按用户昵称、评论内容或图集名模糊匹配（回车或点「搜索」触发），无匹配时展示「没有匹配的评论」空态
- 单条：头像、昵称、角色徽章（付费会员/注册会员）、评论所在图集、时间、正文
- 待审核项提供「通过 / 拒绝」，均二次确认并留痕；处理后移出待审列表
- 已处理项显示结果徽章（已通过=绿 / 已拒绝=红），不再显示模糊的「已处理」
- 分页：每页 5 条，底部页码条（‹ 1 2 ›）；切换 Tab 或搜索时回到第 1 页
- 无待审时展示空态；待审数量同步到侧栏徽章与看板

### 公告管理
- 列表：标题（置顶项带「置顶」徽章）、类型标签、摘要、发布时间、状态
- 新建公告弹窗：类型（通知/更新/活动/维护/规则/置顶）、置顶开关、标题（必填）、摘要、正文（空行分段）
- **编辑**：每行「编辑」复用同一弹窗，标题变「编辑公告 #ID」、按钮变「保存修改」，回填类型/置顶/标题/摘要/正文；保存后列表原地更新并留痕（`announcement.edit`）
- 发布/下线切换（即时生效）、删除（二次确认）
- 分页：每页 6 条，底部页码条（‹ 1 2 ›），新建公告后置顶插入第 1 页
- 无数据时展示「没有公告」空态

### 作者管理
- 列表：方形头像（36×36，8px 圆角；已上传图片则显示图片，未上传则显示渐变色卡 + 作者名首字）+ 作者名、别名、收录套数（按图集实时统计）、风格标签、入驻日期、状态
- 新建作者弹窗：作者名（必填）、别名、**头像上传**、入驻日期、风格标签、简介
- **头像上传**：点击「⬆ 上传头像」选择本地图片（jpg / png / webp，≤ 5MB），56×56 预览即时显示；已上传时出现「移除图片」，点色卡也会放弃图片回到首字头像（两种方式互斥，避免歧义）
- 头像统一按 **1:1 方形**展示，建议原图 ≥ 200×200；前台作者卡与作者主页使用同一张图（未上传时回落到色卡 + 首字），因此上传后无需再单独配置前台
- **编辑**：每行「编辑」复用新建弹窗（标题变「编辑作者 #ID」），回填名称/别名/头像（图片或色卡）/入驻日期/风格/简介；改名后发布页作者下拉即时同步，头像变更记入日志「编辑作者 · 更新头像」
- **删除**：名下仍有图集的作者禁止删除（提示「请先转移或删除图集」）；无图集作者二次确认后删除并留痕
- 新建后作者即刻出现在「发布图集」的作者下拉中
- 分页：每页 6 位，底部页码条；顶部显示「共 N 位」
- 无数据时展示「暂无作者」空态

### 支付流水
> 收益是站点核心指标，独立成页（对应数据库 `pay_order`）

- 顶部四张统计卡（固定全部订单口径，不随筛选变化）：
  - 累计营收（红色大字）：全部已支付订单现金合计
  - 今日营收 + 今日订单笔数
  - 会员订单数 + 现金合计
  - 积分解锁数 + 消耗积分合计
- 筛选：全部 / 会员开通 / 积分解锁；搜索订单号或用户昵称；**支付时间区间筛选**
  - 起止日期双输入框（`type=date`），手动改日期会自动取消快捷按钮高亮
  - 快捷区间：全部时间 / 今天 / 近 7 天 / 近 30 天（按自然日，含当天）
  - 「清除」重置时间区间与搜索词，保留当前业务 Tab
  - 无支付时间的待支付 / 已关闭订单在启用时间筛选时自动排除
  - 副标题实时显示「共 N 笔 · 起~止」，无结果时展示空态
- 表格列：订单号（等宽数字）、用户、业务徽章（会员开通=红 / 积分解锁=灰）、图集或套餐名、支付方式（支付宝 / N 积分）、金额（现金 `¥19.00` 或 `15 分`）、状态徽章（已支付/待支付/已关闭/已退款）、支付时间
- 操作：仅「已支付 + 会员开通」订单显示退款，二次确认（提示退款金额、用户、会员权益同步失效），退款后订单置为已退款、营收实时重算并留痕
- 积分解锁订单不提供退款（积分退回需走用户侧申诉流程，v1 不做）
- 每页 8 笔，底部页码分页
- **导出**：右上角「导出 CSV」，导出**当前全部筛选结果**（业务 Tab + 搜索词 + 时间区间共同生效，不受分页限制）
  - 列：订单号、用户、业务、图集/套餐、支付方式、金额、状态、支付时间
  - UTF-8 BOM 编码，Excel 直接打开不乱码；含逗号/引号字段自动加引号转义
  - 文件名 `sylvie-pay-YYYYMMDD-HHmm.csv`
  - 导出动作写入操作日志（记录笔数与时间区间）；结果为空时提示且不生成文件

### 用户管理
- 按昵称 / 邮箱搜索（回车或点「搜索」触发），无结果展示空态；搜索后回到第 1 页
- 列表：昵称 + 邮箱、角色徽章（管理员/付费会员/注册会员）、积分、会员到期、注册时间、状态
- 操作：重置密码 / 封禁 / 解封（均二次确认，管理员账号不提供这两项操作）
- **重置密码**：确认后生成 `Sy` + 8 位随机字符（去除易混淆的 0/1/i/l/o）的临时密码，弹窗展示该用户昵称与邮箱、临时密码与「复制」按钮，并提示「仅本次展示 / 下次登录强制修改密码 / 原密码立即失效」；关闭弹窗后无法再次查看，操作写入日志 `user.resetpwd`
- 只读查看，不提供内容发布权限分配（v1 仅管理员可发布）
- 分页：每页 8 位，底部页码条；顶部显示当前筛选结果总数

### 友链与配置
- 友链列表：站名 + 一句简介 + 删除（二次确认）；底部输入框添加新友链，同步到前台页脚胶囊
- 站点配置：页脚版权文案、ICP 备案号、年龄声明、内容免责声明、图片水印开关，保存后留痕

### 操作日志
- 表格：时间、操作人、动作标签（发布/下架/审核/删除/封禁/配置修改等，中文映射）、目标、详情
- 最新在前；任何写操作即时插入一条，无需刷新页面
- 分页：每页 8 条，底部页码条；副标题显示日志总条数
- 无日志时展示「暂无操作日志」空态

> 分页口径统一：图集 6 / 评论 5 / 公告 6 / 作者 6 / 支付流水 8 / 用户 8 / 操作日志 8；均支持页码跳转、首页禁用「‹」、末页禁用「›」、结果变少时自动回落到有效页。友链与配置为表单页（非列表页），不分页。

> 交互约定：删除 / 下架 / 退款 / 封禁 / 重置密码 / 导出等关键操作统一走二次确认弹窗；确认回调内部异常会被捕获并以 toast 提示「操作失败：原因」，不会静默无响应（如删除作者时误用不可变数组这类问题会直接暴露）。

## 权限与角色

- **唯一角色**：管理员（`user.role='admin'`），v1 不设运营/审核/财务等细分角色
- 后台不提供注册入口，账号由数据库直接维护；登录后所有页面可见、全部写操作可用
- 前台的发布权限也仅此角色：前台管理员登录后只出现「管理后台 · 发布图集」快捷入口，
  完整的发布与运营流程在本后台完成
- 退出登录（二次确认）后回到后台登录页，会话失效

## 与前台 / 数据库的关系

- **独立部署**：后台可单独发版，不影响前台；前台下线后台仍可维护内容
- **共用数据库**：图集、作者、公告、订单、评论等表由后台写入、前台读取；
  `album.created_by` 记录发布管理员，`admin_op_log` 记录后台全部写操作
- **账号体系**：后台不提供注册，账号由数据库 `user` 表 `role='admin'` 决定；封禁用户、退款等操作直接反映到前台
- **配置下发**：友链、页脚文案、水印开关等 `sys_config` 配置项由后台维护，前台实时读取

## v1 范围外

- 多管理员与细粒度角色权限（运营 / 审核 / 财务）
- 全站多报表导出（v1 仅支付流水支持按筛选结果导出 CSV，其余列表不提供导出）
- 支付对账与自动退款回调
- 评论关键词自动过滤
- 图集定时发布与草稿自动保存
