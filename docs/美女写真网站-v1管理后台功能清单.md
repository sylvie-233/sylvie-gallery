# 希尔薇图集 · v1 管理后台功能清单

> **独立项目**：管理后台与前台（`美女写真网站-v1原型设计.html`）是两个独立的应用，
> 各自独立部署、独立登录，仅共用同一套数据库（见 `美女写真网站-v1数据库设计.sql`，权限依赖 `user.role='admin'`）。
> **仅面向桌面端**：后台是运营人员在内网 / 桌面浏览器里使用的工具，按 1280px 及以上的桌面布局设计（侧栏 220px 固定、表格多列并排），不做移动端适配；移动端只面向 C 端前台。窄窗口下表格次要列（`hide-m`）会自动隐藏以保证可读，这属于降级显示而非移动端适配。
> 原型：`美女写真网站-v1管理后台原型.html`（单文件，深色 + 玫红设计语言，与前台视觉统一）。
>
> **登录**：邮箱 + 密码，仅 `role=admin` 可进入；v1 无多角色权限分配，一个后台即全部运营能力。
> 前台管理员登录后仅显示「管理后台 · 发布图集」快捷入口（进入图集编辑器），内容管理与运营操作全部在本后台完成。

## 功能模块

### 登录入口
- 后台是独立应用，**未登录访问任意后台地址都先落到登录页**（`#loginScr`，全屏覆盖层，独立于后台三栏布局）；登录成功后才显示侧栏与内容，退出登录即回到该页
- 表单：账号、密码、记住我（**无忘记密码功能**，密码遗失由管理员线下重置）；账号框自动聚焦，账号框回车跳到密码框、密码框回车直接提交
- 校验：账号或密码不匹配时，卡片下方红字提示「账号或密码不正确，请重试」并左右抖动，密码框自动全选便于重输
- 演示账号 `admin` / `123456`（登录页底部有提示，正式上线前删除该提示）；正式环境对接 `user` 表 `role='admin'` + bcrypt 密码校验（数据库种子账号 `admin@sylvie.cc`），建议补登录失败次数限制、会话过期与操作日志留痕
- 登录成功：登录层淡出 + toast「欢迎回来，admin」，落到数据看板
- 退出登录：侧栏底部入口 → 二次确认 → 回到登录页（清空密码、重置到数据看板、账号框聚焦）

### 整体结构
- 左侧导航 11 项，按实际使用频率分为 4 组（组间以灰色小标题分隔）：
  - **内容管理**：图集管理 / 图集编辑器 / 标签管理 / 作者管理（图集相关操作集中在一处，维护标签与作者后可直接进编辑器发布）
  - **互动运营**：评论审核（未处理数红色徽章）/ 公告管理
  - **交易与用户**：支付流水 / 用户管理（涉钱操作相邻，便于对照用户与订单）
  - **系统**：友链与配置 / 操作日志
  - 「数据看板」位于导航最顶部，不参与分组
- 顶部：面包屑（管理后台 / 当前页）+ 右侧管理员账号与角色角标
- 底部：返回前台、退出登录（二次确认，确认后回到登录页）
- 所有写操作成功后追加一条操作日志，日志页实时刷新
- **列表页工具栏统一规范**：所有表格页在面板顶部使用同一套工具栏（同一组件、同一 14px 间距）
  - 页面标题行只放「标题 + 副标题计数 + 主操作按钮（发布图集 / 新建公告 / 新建标签 / 新建作者）」
  - 工具栏左侧放筛选 Tabs（图集状态 / 评论状态 / 标签状态 / 订单业务与状态）；无 Tabs 的页面搜索框靠右
  - 工具栏右侧放搜索框（回车或点「搜索」触发，**搜索后自动回第 1 页**）与次要操作（支付流水的导出 CSV）
  - 多层筛选的页面（支付流水）使用第二行工具栏放时间区间 + 快捷时间 Tab + 清除，行距统一
- **视觉与前台同源**：深色 + 玫红设计语言完全对齐前台原型——主按钮玫红渐变（`linear-gradient(135deg,#ff2d55,#ff4b6b)`）带红色柔光投影、输入框聚焦玫红描边、页面顶部玫红径向光晕背景、文字选区玫红，均与前台 Header / 弹窗 / 按钮的视觉规范一致

### 数据看板
- **今日运营指标**（第一行 4 张卡）：今日营收（现金订单实时计算，玫红高亮）、积分解锁（套数 + 消耗积分）、今日新增用户、今日 PV（含 UV 与环比，演示值）；**营收 / 解锁与支付流水页同口径**，避免两页数字打架
- **站点规模指标**（第二行 4 张卡）：图集总数（含已发布/草稿拆分）、注册用户、付费会员（本月新增）、待审核评论（橙色警示）
- **营收趋势图（三档切换）**：纯 CSS 柱状图（无图表库依赖），标题旁页签切换「近 7 天 / 近一个月 / 近六个月」，切换后保持选中态（切页返回仍生效）。近 7 天按日 7 根柱；近一个月按日 30 根细柱（密集模式：隐藏金额标签、日期标签每 5 天一个且首尾贴边）；近六个月按自然月聚合 6 根柱（当月累计至今天）。柱高按面板实际高度自适应（切页返回、窗口缩放自动重算），无订单日灰色弱化，悬停显示当日/当月金额；数据优先取真实支付流水（`pay_order` 现金订单），无订单日为按日期散列的稳定演示值并带站点成长系数（越早月份越低），三档之间同一天数值一致；标题右侧「查看支付流水 ›」直达流水页；脚注条三项汇总随档位变化——近 7 天/一个月为「合计 / 日均 / 单日最高（含日期）」，近六个月为「合计 / 月均 / 单月最高」
- **待办事项**：待审核评论 / 草稿待发布 / 已下架图集 / 今日新订单，四项均带实时计数徽章（为 0 时灰化），点击直达对应列表（草稿与已下架自动切换到对应筛选页签）
- **快捷操作**（位于「最近发布」右侧列，热搜词下方）：发布新图集、发布公告、修改站点配置
- **布局规则**：看板分四段——指标卡两行 → 「趋势图 | 待办事项」两栏（两卡等高对齐，图表高度随待办卡内容自适应封顶，不留大片空白）→ 「最近发布 | 热搜词 + 快捷操作」两栏（`align-items:start`，右列卡片按内容高度堆叠，不被左侧表格拉伸）→ 结束；≤1080px 全部折叠为单列
- **最近发布表格**：最新 6 条，缩略图 + 标题 + 作者 + `P/V` 规格 + 发布时间 + 状态徽章（已发布/草稿/已下架）；标题右侧「全部图集 ›」直达图集管理
- **热搜词 TOP5**：展示近 7 天搜索热度最高的 5 个关键词（对应数据库 `search_log` 聚合），用于发现「0 结果热词」与选题参考

### 图集管理
- 状态筛选：全部 / 已发布 / 草稿 / 已下架；按标题或作者搜索（回车或点「搜索」，**搜索自动回第 1 页**）
- 表格列：封面缩略图 + 标题 + `#ID`、作者、`P/V` 规格、解锁积分、浏览/收藏（万级折算）、发布时间、状态徽章（推荐图集在状态旁追加玫红「推荐」徽章）
- 操作：已发布可「下架」，草稿/已下架可「发布/上架」，均二次确认；**「推荐 / 取消推荐」**一键切换瀑布流「个人推荐」池（对应 `album.is_recommended`，二次确认并留痕）；「删除」二次确认后不可恢复
- **编辑**：每行「编辑」进入**整页图集编辑器**（不再使用小弹窗，与发布共用同一编辑器，见下节），标题变「编辑图集」、副标题带 `#ID` 与状态徽章
  - 可改：标题（必填 1–60 字，空值拦截）、归属作者、解锁积分、简介、标签（搜索下拉添加，最多 8 个，已选标签以 `#标签` 胶囊展示，点 ✕ 或再点下拉项即可移除；**隐藏状态的标签不再出现在下拉中**）
  - **媒体可编辑**：加载图集现有图片 / 视频进媒体工作台，可增删、拖拽调序、指定封面、大图预览（详见「图集编辑器」章节）；保存后 `album_image` 顺序、`album.videos` 与封面同步更新
  - 编辑态按钮组：已发布图集为「放弃修改 + 保存修改」；草稿为「保存修改 + 发布图集」（可直接转发布）
  - 保存后回到图集管理并刷新列表与看板，前台立即生效；操作日志记录「编辑图集」并列出改动字段（标题 / 作者 / 积分 / 简介 / 标签 / 媒体 / 发布）
- 每页 6 套，底部页码分页；空结果兜底提示
- 操作后看板统计与列表同步刷新

### 图集编辑器（新建 / 编辑共用整页）
> 核心功能不塞小弹窗：发布与编辑共用一个整页编辑器，左宽栏媒体工作台 + 右窄栏基本信息（窄窗口折叠单列，右栏取消吸顶）。

- **页面结构**：标题行（发布图集 / 编辑图集 + 状态徽章）+「👁 预览」与「返回列表」；左栏媒体工作台，右栏基本信息与操作按钮
- **媒体工作台（图片页签）**
  - 虚线上传区：**点击打开系统文件选择框**（支持多选）或拖拽图片文件投放，选中的图片生成真实缩略图预览；最多 99 张；下方提供「添加 3 张示例图」演示入口（无素材时快速预览效果）
  - 缩略图网格：每张带**展示顺序编号**（编号即前台详情页顺序）、悬停浮层操作——👁 预览 / ★ 设为封面 / ‹ › 前后微调 / ✕ 移除
  - **拖拽排序**：按住缩略图拖到目标位置松手即换位，拖拽中半透明、目标位玫红描边；封面标记随位置移动自动跟随
  - 封面：点击 ★ 指定任意一张（带玫红「封面」角标），未指定时默认第 1 张；标题行实时显示「封面：第 N 张」
- **媒体工作台（视频页签）**：独立上传区，点击打开文件选择框或拖拽视频文件投放（记录真实文件名），视频条目列表（名称 + 时长 + 上移 / 下移 / 删除），最多 3 个；v1 暂不支持在线视频预览
- **大图预览器（灯箱式）**：参考主流图片查看器——近全屏舞台（`min(94vw,1320px) × min(90vh,900px)`，图片 `contain` 完整显示不裁切），顶部渐变带上悬浮「第 x / n 张」计数胶囊、当前封面徽章、快捷键提示与关闭按钮，左右圆形箭头垂直居中悬浮（hover 变玫红），底部渐变带为缩略图胶片条（点击任意张跳转、当前张玫红描边、封面带 ★ 标记、超出可横向滚动并自动滚到可视区）；‹ › 或 ← → 方向键循环切换，Esc / 点遮罩关闭；窄屏（≤860px）自动收窄内边距、缩小箭头与缩略图并隐藏提示文字
- **基本信息（右栏）**：标题（必填 1–60 字）、归属作者（**已隐藏作者不出现**，编辑时保留原作者并带「已隐藏」后缀）、解锁积分（0–99 钳制）、简介、标签搜索下拉（最多 8 个，数据源为展示中的标签）
- **标签收录数联动**：发布 / 上架图集时对应标签 `tag.use_count` +1，下架 / 删除 / 编辑换标签时按差值增减，标签管理页「收录套数」与前台标签云始终同口径（按已发布图集计）
- **提交**：
  - 新建：「发布图集」→ 二次确认（标题、作者、图片 / 视频数）→ 置为已发布；「保存草稿」→ 暂存为草稿，自动跳到图集管理「草稿」页签
  - 编辑：保存后按改动字段留痕（含「媒体（顺序/封面/增删）」）；草稿直接「发布图集」可转正
  - 提交后回到图集管理并刷新列表、标签与看板；再次经导航进入编辑器时自动重置为新建模式
- 是否进入瀑布流「个人推荐」池在发布后于图集管理中按套设置

### 评论审核
- 分段 Tab：待审核 / 已通过 / 已拒绝
- **时间筛选**：与支付流水同一套快捷页签（全部时间 / 今天 / 近 7 天 / 近 30 天 / 自定义），「自定义」展开日期区间，手动改日期自动切「自定义」；按评论提交日期（`comment.created_at`）比对，与状态 Tab、搜索叠加生效
- 搜索：按用户昵称、评论内容或图集名模糊匹配（回车或点「搜索」触发），无匹配时展示「没有匹配的评论」空态
- 单条卡片布局与主流审核后台一致：**左侧内容区**（头像、昵称、角色徽章（付费会员/注册会员）、评论所在图集、时间、正文），**右侧固定操作列**（按钮与正文顶部对齐、靠右）——浏览动线与操作动线分离，长评论不会把按钮挤下去
- 卡片悬停浅色高亮，便于逐行定位
- 待审核项右侧提供「通过 / 拒绝」，均二次确认并留痕；处理后移出待审列表
- 已处理项右侧显示结果徽章（已通过=绿 / 已拒绝=红）+「删除」，不再显示模糊的「已处理」
- **删除已通过 / 已拒绝评论**：两类已处理项均提供「删除」，二次确认后移除且不可恢复（对应 `comment.status='deleted'`），并留痕 `comment.delete`
- 分页：每页 5 条，底部页码条（‹ 1 2 ›）；切换 Tab 或搜索时回到第 1 页
- 空态文案随 Tab 变化（「没有待审核 / 已通过 / 已拒绝的评论」）；待审数量同步到侧栏徽章与看板

### 公告管理
- 列表：标题（`is_top` 项标题前带「置顶」徽章，置顶排首位）、类型标签、摘要、发布时间、状态
- **组合筛选**：类型（全部类型 / 更新 / 活动 / 维护 / 规则 / 通知，**置顶是展示属性不作为类型**）、状态（全部状态 / 已发布 / 已下线）下拉 + 时间快捷页签（全部时间 / 今天 / 近 7 天 / 近 30 天 / 自定义，「自定义」展开日期区间）——三类筛选与标题 / 摘要搜索叠加生效，副标题显示匹配数；无匹配时展示「没有符合条件的公告」空态
- 新建公告弹窗：类型（通知/更新/活动/维护/规则）、**置顶开关**（独立布尔属性，对齐数据库 `announcement.is_top`；置顶公告排列表首位，标题前带「置顶」徽章）、标题（必填）、摘要、正文（空行分段）
- **编辑**：每行「编辑」复用同一弹窗，标题变「编辑公告 #ID」、按钮变「保存修改」，回填类型/置顶/标题/摘要/正文；保存后列表原地更新并留痕（`announcement.edit`）
- 发布 / 下线切换**均二次确认**（即时生效并留痕）、删除（二次确认）
- 分页：每页 6 条，底部页码条（‹ 1 2 ›），新建公告后置顶插入第 1 页
- 无数据时展示「没有公告」空态

### 标签管理
> 前台「标签云」与图集筛选的数据源（对应数据库 `tag` / `album_tag`），标签统一以 `#前缀` 展示

- 列表：`#标签名`、收录套数（冗余计数 `tag.use_count`）、创建时间、状态徽章（展示中=绿 / 已隐藏=红）
- 筛选：全部 / 展示中 / 已隐藏；按标签名搜索（回车或点「搜索」，回第 1 页）
- **新建 / 编辑**：弹窗录入 1–20 字标签名，重名校验拦截（含引号等特殊字符拦截，避免下拉交互异常）；编辑可重命名，所有已收录图集的标签同步更新并留痕（`tag.edit`）
- **隐藏 / 展示**：二次确认切换 `tag.status`；隐藏后前台标签云不再展示、图集发布与编辑的标签下拉中不可再选（`tag.hide` / `tag.show`）
- **删除**：仅未被任何图集收录的标签可删（已收录提示「已被 N 套图集收录，不可删除」，可先隐藏），二次确认后软删除并留痕（`tag.delete`）
- 新建标签即刻出现在发布 / 编辑图集的标签搜索下拉中
- 分页：每页 8 个，底部页码条；副标题实时显示「共 N 个 · 展示中 X 个」

### 作者管理
- **状态筛选**：全部 / 展示中 / 已隐藏（Tab 页签，与标签管理一致）；与搜索叠加生效，副标题显示匹配数，无匹配时展示「没有符合条件的作者」空态
- **按作者名 / 别名 / 风格搜索**（回车或点「搜索」），副标题显示匹配数
- 列表：方形头像（36×36，8px 圆角；已上传图片则显示图片，未上传则显示渐变色卡 + 作者名首字）+ 作者名、别名、收录套数（按图集实时统计）、风格标签、**排序权重**、状态（展示中=绿 / 已隐藏=红）
- 新建作者弹窗：作者名（必填）、别名、**头像上传**、**排序权重（越大前台越靠前，默认 10）**、风格标签、简介；列表按权重降序排列。**不设入驻日期字段**——图集与作者均由系统管理员维护，非作者自行注册入驻
- **头像上传**：点击「⬆ 上传头像」选择本地图片（jpg / png / webp，≤ 5MB），56×56 预览即时显示；已上传时出现「移除图片」，点色卡也会放弃图片回到首字头像（两种方式互斥，避免歧义）
- 头像统一按 **1:1 方形**展示，建议原图 ≥ 200×200；前台作者卡与作者主页使用同一张图（未上传时回落到色卡 + 首字），因此上传后无需再单独配置前台
- **隐藏 / 展示**：二次确认切换 `author.status`；隐藏后前台作者卡与作者主页不再展示（其名下图集仍可通过直链访问），图集编辑器的作者下拉同步剔除（`author.hide` / `author.show`）
- **编辑**：每行「编辑」复用新建弹窗（标题变「编辑作者 #ID」），回填名称/别名/头像（图片或色卡）/排序权重/风格/简介；改名后发布页作者下拉即时同步，头像变更记入日志「编辑作者 · 更新头像」
- **删除**：名下仍有图集的作者禁止删除（提示「请先转移或删除图集」）；无图集作者二次确认后删除并留痕
- 新建后作者即刻出现在「图集编辑器」的作者下拉中
- 分页：每页 6 位，底部页码条；顶部显示「共 N 位 · 前台展示 X 位」
- 无数据时展示「暂无作者」空态

### 支付流水
> 收益是站点核心指标，独立成页（对应数据库 `pay_order`）

- 顶部四张统计卡（固定全部订单口径，不随筛选变化）：
  - 累计营收（红色大字）：全部已支付订单现金合计
  - 今日营收 + 今日订单笔数
  - 会员订单数 + 现金合计
  - 积分解锁数 + 消耗积分合计
- 筛选：业务 Tab（全部 / 会员开通 / 积分解锁）+ 状态 Tab（待支付 / 已退款）；搜索订单号或用户昵称；**时间快捷页签筛选**
  - 快捷页签为唯一时间入口：全部时间 / 今天 / 近 7 天 / 近 30 天 / 自定义（按自然日，含当天）；选中快捷项自动填充日期区间，无需手动输入
  - **自定义区间**：点「自定义」页签或手动修改日期时才展开起止日期输入框（`type=date`），平时隐藏以保持工具栏整洁；手动改日期自动切到「自定义」页签
  - 生效区间显示在列表副标题（如「共 10 笔 · 2026-11-12 ~ 2026-11-18」）；「全部时间」即重置时间筛选，不设冗余清除按钮
  - 无支付时间的待支付 / 已关闭订单在启用时间筛选时自动排除
  - 副标题实时显示「共 N 笔 · 起~止」，无结果时展示空态
- 表格列：订单号（等宽数字）、用户、业务徽章（会员开通=红 / 积分解锁=灰）、图集或套餐名、支付方式（支付宝 / N 积分）、金额（现金 `¥19.00` 或 `15 分`）、状态徽章（已支付/待支付/已关闭/已退款）、支付时间
- 操作：仅「已支付 + 会员开通」订单显示退款，二次确认（提示退款金额、用户、会员权益同步失效），退款后订单置为已退款、营收实时重算并留痕（退款时间与原因落库 `pay_order.refund_at` / `refund_reason`）；**用户列表中该会员的会员状态同步失效**（演示口径：退款即收回会员身份）
- 积分解锁订单不提供退款（积分退回需走用户侧申诉流程，v1 不做）
- **管理员赠送会员**不在流水页出现独立订单入口，赠送动作落 0 元赠送单（`pay_type='admin'`）+ 操作日志，便于与支付宝现金营收区分口径
- 每页 8 笔，底部页码分页
- **导出**：右上角「导出 CSV」，导出**当前全部筛选结果**（业务 Tab + 搜索词 + 时间区间共同生效，不受分页限制）
  - 列：订单号、用户、业务、图集/套餐、支付方式、金额、状态、支付时间
  - UTF-8 BOM 编码，Excel 直接打开不乱码；含逗号/引号字段自动加引号转义
  - 文件名 `sylvie-pay-YYYYMMDD-HHmm.csv`
  - 导出动作写入操作日志（记录笔数与时间区间）；结果为空时提示且不生成文件

### 用户管理
- **角色筛选**：全部角色 / 管理员 / 付费会员 / 注册会员（下拉，与公告管理一致）；**状态筛选**：全部状态 / 正常 / 已封禁（下拉）；两者与昵称 / 邮箱搜索叠加生效，副标题显示「匹配 N 位 · 共 M 位」，无匹配时展示「没有符合条件的用户」空态
- 按昵称 / 邮箱搜索（回车或点「搜索」触发），无结果展示空态；筛选或搜索后回到第 1 页
- 列表：昵称 + 邮箱、角色徽章（管理员/付费会员/注册会员）、解锁积分、会员到期、注册时间、状态
- 操作：调积分 / 赠会员 / 重置密码 / 封禁 / 解封（均二次确认或弹窗确认，管理员账号不提供这些操作）
- **调整积分**：弹窗展示用户昵称 / 邮箱 / 当前解锁积分余额，输入变动值（正数发放、负数扣减）+ 调整原因（活动奖励 / 运营补偿 / 违规扣除 / 其他），确认后余额即时生效并留痕 `user.points`（记录调整前后值）；余额不为负，扣减超出按 0 处理
- **赠送会员**：二次确认后开通付费会员 30 天，已有会员在剩余有效期上叠加（不清零），角色徽章同步变为付费会员，留痕 `user.grantvip`；赠送走 0 元赠送单（`pay_type='admin'`）不计入现金营收
- **重置密码**：确认后生成 `Sy` + 8 位随机字符（去除易混淆的 0/1/i/l/o）的临时密码，弹窗展示该用户昵称与邮箱、临时密码与「复制」按钮，并提示「仅本次展示 / 下次登录强制修改密码 / 原密码立即失效」；关闭弹窗后无法再次查看，操作写入日志 `user.resetpwd`
- 不提供内容发布权限分配（v1 仅管理员可发布）
- 分页：每页 8 位，底部页码条；顶部显示当前筛选结果总数

### 友链与配置
- **卡片布局**：上排「站点配置 | 会员套餐」两张同类型表单卡并排（高度相近、语义同类），下排「友情链接」通栏卡片收尾——避免旧布局中矮卡配高卡、末尾卡片右侧留空洞的问题；窄窗口下三卡折叠为单列
- 友链卡片（通栏）：条目以自适应多列网格铺排（站名 + 一句简介 + **跳转链接** + 删除；链接显示为域名 `xxx.com ↗`，悬停展示完整地址，点击新标签页打开；简介超长省略号截断，删除二次确认）；底部一行「站名 + 简介 + 链接 + 添加友链」输入区，**链接为必填**（校验以 `http(s)://` 开头且含域名，对应 `friend_link.url` NOT NULL）；无友链时显示通栏空态，页脚不展示胶囊
- 站点配置：页脚版权文案、ICP 备案号、年龄声明、内容免责声明、**每日签到积分**（对应 `sys_config.checkin.points`，注册会员每日签到可领）、图片水印开关（与签到积分同行排布；仅控制未解锁预览的前 3 张，积分解锁/付费会员的在线查看与下载均为原图），保存后留痕
- **会员套餐**（对应 `membership_plan` 表，v1 仅月卡）：月卡价格（元）、有效天数、权益文案（每行一条，展示在前台会员卡）；保存后前台会员页与详情页解锁区同步展示新价格；已开通会员的有效期不受调价影响，续费按剩余天数叠加；留痕 `config.plan`

### 操作日志
- **动作筛选**：下拉按类别分组（图集 / 评论 / 公告 / 标签 / 作者 / 用户 / 友链 / 配置 / 订单 / 流水导出，optgroup），选项与动作中文映射表自动同步，新增动作无需手动维护下拉
- **时间筛选**：与其他列表页同一套快捷页签（全部时间 / 今天 / 近 7 天 / 近 30 天 / 自定义，「自定义」展开日期区间），按日志时间（`admin_op_log.created_at`）比对
- 动作、时间与关键词搜索三者叠加生效；副标题显示匹配数；无匹配时展示「没有符合条件的日志」空态
- **按动作标签 / 目标 / 详情关键词搜索**（回车或点「搜索」），副标题显示匹配数
- 表格：时间、操作人、动作标签（发布/存草稿/上下架/推荐/审核/删除/标签/封禁/积分调整/赠送会员/配置与套餐修改/退款/导出等，中文映射）、目标、详情、操作
- **点击查看详情**：整行可点击（也可点操作列「详情」按钮）打开「操作日志详情」弹窗，展示日志编号、时间、操作人、动作（中文标签 + 原始 action 代码，如 `album.publish`）、目标、完整详情、来源 IP——字段与数据库 `admin_op_log`（id / action / target_type+target_id / detail / ip / created_at）一一对应
- 最新在前；任何写操作即时插入一条（自动分配递增编号与来源 IP），无需刷新页面
- 分页：每页 8 条，底部页码条；副标题显示日志总条数
- 无日志时展示「暂无操作日志」空态

> 分页口径统一：图集 6 / 评论 5 / 公告 6 / 标签 8 / 作者 6 / 支付流水 8 / 用户 8 / 操作日志 8；均支持页码跳转、首页禁用「‹」、末页禁用「›」、结果变少时自动回落到有效页。友链与配置为表单页（非列表页），不分页。

> 交互约定：删除 / 下架 / 退款 / 封禁 / 重置密码 / 导出等关键操作统一走二次确认弹窗；确认回调内部异常会被捕获并以 toast 提示「操作失败：原因」，不会静默无响应（如删除作者时误用不可变数组这类问题会直接暴露）。

## 权限与角色

- **唯一角色**：管理员（`user.role='admin'`），v1 不设运营/审核/财务等细分角色
- 后台不提供注册入口，账号由数据库直接维护；登录后所有页面可见、全部写操作可用
- 前台的发布权限也仅此角色：前台管理员登录后只出现「管理后台 · 发布图集」快捷入口（跳转图集编辑器），
  完整的发布与运营流程在本后台完成
- 退出登录（二次确认）后回到后台登录页，会话失效

## 与前台 / 数据库的关系

- **独立部署**：后台可单独发版，不影响前台；前台下线后台仍可维护内容
- **共用数据库**：图集、作者、标签、公告、订单、评论等表由后台写入、前台读取；
  `album.created_by` 记录发布管理员，`admin_op_log` 记录后台全部写操作（含推荐池切换、标签维护、积分调整、赠送会员、套餐修改）
- **账号体系**：后台不提供注册，账号由数据库 `user` 表 `role='admin'` 决定；封禁用户、退款、赠送会员、调整积分等操作直接反映到前台
- **配置下发**：友链、页脚文案、水印开关、签到积分、会员套餐等 `sys_config` / `membership_plan` 配置项由后台维护，前台实时读取
- **标签联动**：`tag.status=0`（隐藏）的标签前台标签云不再展示、图集发布/编辑不可再选；重命名标签时 `album_tag` 关联的展示名同步更新；`tag.use_count` 由图集发布 / 编辑 / 删除时同步维护
- **推荐池联动**：`album.is_recommended=1` 的图集进入前台瀑布流「个人推荐」候选池，与浏览 / 收藏偏好共同决定瀑布流内容

## v1 范围外

- 多管理员与细粒度角色权限（运营 / 审核 / 财务）
- 全站多报表导出（v1 仅支付流水支持按筛选结果导出 CSV，其余列表不提供导出）
- 支付对账与自动退款回调（退款原因 / 时间已预留字段，`pay_order.refund_at` / `refund_reason`）
- 评论关键词自动过滤
- 图集定时发布与草稿自动保存（已支持手动「保存草稿」，定时发布与自动保存不做）
- 批量向用户推送站内通知（用户通知由审核结果 / 作者更新等业务事件自动产生）
